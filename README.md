# Import Clearance Document Checker

Finds mismatches between the commercial invoice, packing list and bill of lading
before submission. A person approves. It never submits anything to customs.

Status: work in progress (AMD Developer Hackathon ACT III, Reinvent Commerce).

## How it works
AI extracts, code verifies, AI explains, human approves.
